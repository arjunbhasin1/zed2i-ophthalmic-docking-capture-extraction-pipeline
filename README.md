# Ophthalmic Trocar Docking Perception Pipeline

This repository contains the source code for the data acquisition and preprocessing 
pipeline used in the BEng Research Project: *External-camera-guided trocar docking 
system for ophthalmic robotic surgery*.

## Folder Structure
- `capture/`: Scripts for camera initialization, preview, and recording.
- `preprocessing/`: Scripts for frame extraction, stereo-splitting, and metadata generation.

## Requirements
- OpenCV
- Numpy
- ZED 2i Camera (Stereolabs)
